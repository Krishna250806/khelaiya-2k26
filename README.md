# khelaiya-2k26

Official web application for **NUV खेलैया 2026** at **Jyoti Party Plot, Vadodara** — A grand cultural celebration of Garba, tradition, music, and togetherness.

## Features
- **Royal Double-Leaf Haveli Doors**: 3D interactive gate entrance experience with sound/lighting effects.
- **3D Three.js Dandiya Scene**: Responsive, hardware-adaptive Dandiya and particle celebration in the Hero section.
- **Super Responsive**: Fluid layouts engineered for mobile phones (360px–414px), tablets, and ultra-wide displays.
- **Low-End Device Optimized**: Automatic GPU throttling, clamped DPR, off-screen canvas pause, and 98.7% image payload reduction.
- **Interactive Sections**:
  - Sacred Navratri Heritage & Royal Haveli Framed Showcase
  - Unified Event Experience Cards (Garba, Dandiya, Music, Folk Heritage)
  - Title Sponsors with Official Logos & Infinite Toran Partner Marquee
  - Organizing Committee & Team Heads
  - Registration Modal with Real-Time Notification
  - Direct Outreach Sponsorship Direct-Dial Links
  - Lightbox Gallery Carousel
  - Event Details & Guidelines FAQ Accordion

## Technology Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom CSS Design System
- **3D & Canvas**: Three.js
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Local Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```
